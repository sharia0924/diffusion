# ⚠️ 历史存档：v1（错误评测口径）结果，请勿引用

本目录下的结果产生于 v2 测量口径修复**之前**，包含以下已确认的错误：

1. `crop` 攻击用 `torch.roll` 实现，是**循环平移**而非裁剪；
   例如 `robustness.md` 里的 `crop+2px = 0.494/0.344` 没有裁剪语义。
2. 再生攻击代价用 `PSNR(regen, stego)`，参照物是被污染的载密图。
3. nonce 由 `H(cover)` 派生，方案并非盲提取。
4. 把"槽位定位 AUC=0.79"当作"攻击失败"，且把派生参数空间 1354 bit
   当作密钥强度（真实密钥熵为 64 bit）。

修复说明与修复后的结果见仓库根目录 `NEXT_STEPS.md` 与 `results/`。
保留本目录仅用于对比"口径变化带来的结论差异"。
